# Spotify Backstage — Software Catalog

**Source:** https://backstage.spotify.com/learn/backstage-for-all/3-software-catalog/

## What the Software Catalog Is

"A centralized system that keeps track of ownership and metadata for all the software in your ecosystem." Functions as a software graph — not a flat spreadsheet.

## How It Works

Metadata files stored alongside code are "harvested and visualized in Backstage," making everything accessible through a unified interface.

## Key Concepts

**Metadata tracked:**
- Service names
- Responsible teams
- Readiness status (production-ready vs. experimental)
- Broader ecosystem context

**Relationship mapping:**
Documents how services depend on databases, message brokers, shared libraries, and other components.

## Use Cases

1. Consolidated management of services at any scale
2. Enhanced discoverability and clear ownership assignment
3. Unified visibility into owned services and related resources
4. Plugin integration (monitoring, testing, alerting)
5. Scalable from startups to Fortune 500

## Integration

"Backstage's plugin architecture can integrate with the Software Catalog's metadata and pull in other management features like resource monitoring and testing."
