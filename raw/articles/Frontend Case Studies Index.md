# Frontend Case Studies Index

**Source:** https://github.com/andrew--r/frontend-case-studies
**Website:** https://frontendcs.com (as of January 2025)

## Overview

Curated collection of technical talks and articles documenting real-world frontend development at enterprise scale. 200+ companies featured. Organized alphabetically.

"Articles like 'Building a simple todo list with [framework or technology name]' won't teach you how that framework or technology solves real-world problems and works at a large scale."

## Topic Categories

### Performance & Optimization
Airbnb, Netflix, Instagram — code-splitting, SSR, bundle size reduction, Core Web Vitals.

### Architecture & Tooling
Uber, Shopify, Twitter — monorepo management, webpack, build system scaling.

### Framework Migration
Dropbox (CoffeeScript → TypeScript), GitHub (jQuery removal), Discord (React upgrades), Etsy (SCSS adoption).

### Type Safety
Bloomberg, Airbnb, Figma — large TypeScript migrations, strict type checking at scale.

### Design Systems
Atlassian, Datadog, DoorDash — scalable UI components, theming across multiple products.

### Testing & Quality
Slack, BuzzFeed, LinkedIn — snapshot testing, accessibility automation, performance measurement.

### Accessibility & i18n
GOV.UK, Badoo, Etsy — localization infrastructure, WCAG compliance at scale.

### Emerging Technologies
Figma, Google Sheets (WebAssembly), Airbnb, Discord (React Native), Flipkart, Ele.me (PWAs), service workers.
