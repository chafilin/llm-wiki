# Buildkite — Case Studies

**Source:** https://buildkite.com/resources/case-studies/

## Reddit

- Build times: ~30% reduction for iOS and Android
- Queue times: from several minutes → ~5 seconds
- Git/container caching: checkout from minutes → 30-40 seconds
- Replaced 6,000-line YAML with reusable pipeline steps
- Automatic build cancellation for stale runs

## PagerDuty

- 99% of production builds on Buildkite
- 1,000,000 builds (Jan–Oct 2023)
- 20% faster incident resolution time

## Intercom

- Test times: 25 min → 3 min (85% reduction)
- 4,000,000 job minutes/month
- Enabled 150 daily deployments

## Elastic (Kibana)

- Pipeline run time: 3 hours → 55 minutes (70% reduction)
- Cloud infrastructure spending: ~75% reduction

## Shopify

- Build times: under 5 minutes
- 8,000 active pipelines
- 300,000,000 jobs (Jan–Oct 2023)
- Engineering team grew 300% while maintaining performance

## REA Group

- 120,000 builds/month
- Team setup time: weeks → days (80% reduction)
