# Bazel — Who's Using Bazel

**Source:** https://bazel.build/community/users

## Overview

Community page listing companies and open-source projects that use Bazel, Google's build system.

## Major Adopters

**Google** — All Google software uses Bazel; designed for millions of daily builds at Google scale.

**Uber** — One of the largest Go monorepos; 900+ developers.

**Dropbox** — TypeScript/Python/Go/C/Rust in distributed build environments.

**Twitter** — Migrated from Pants to Bazel as primary build tool.

**Stripe** — Used in build and test pipelines.

## Performance Results

| Company | Before | After |
