## Cognitive cost of AI tool use
MIT EEG study (2025) found that habitual LLM use for cognitive tasks measurably reduces brain connectivity, memory retention, and sense of authorship — effects that compound across sessions. The term for this is [[Cognitive Debt]]. Key implication: using AI to produce artifacts may improve the artifact while degrading the underlying skill. Higher-competence users can avoid this by using AI Socratically rather than as an answer-generator. [[Your Brain on ChatGPT — Cognitive Debt]]
