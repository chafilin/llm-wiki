## Summary
An Interaction Design Foundation overview comparing responsive and adaptive design approaches, covering their definitions, how each works technically, trade-offs in UX, SEO, speed, cost, and control, and decision criteria for choosing between them. Also briefly addresses the declining standalone mobile site strategy.

## Key takeaways
- Responsive design (Ethan Marcotte): single fluid layout using media queries; content rearranges continuously with viewport changes.
- Adaptive design (Aaron Gustafson, 2011): multiple fixed layouts (6 standard breakpoints: 320, 480, 760, 960, 1200, 1600px); server/browser detects screen size and serves matching layout.
- Adaptive sites are typically 2–3x faster than responsive ones on mobile due to serving device-appropriate assets.
- Responsive wins on SEO (single URL) and implementation cost; adaptive wins on per-device control, mobile performance, and ad optimization.
- Adaptive is high-maintenance: multiple layouts must stay synchronized; "in-between" screen sizes (tablets, netbooks) are underserved.
- Standalone mobile sites (m. prefix) have declined; Google treats responsive and adaptive equally for search ranking.
- Choose responsive for speed-to-market and SEO; choose adaptive when page speed is critical or device-specific UX is a core requirement.
