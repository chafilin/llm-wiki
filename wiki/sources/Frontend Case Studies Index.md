## Summary
Curated GitHub repository (now also at frontendcs.com) listing 200+ companies' technical talks and articles about real-world frontend engineering. Organized alphabetically by company.

## Key takeaways
- "Articles like 'Building a simple todo list with X' won't teach you how X solves real-world problems"
- 200+ companies; topics: performance, architecture, migration, type safety, design systems, testing, accessibility, i18n, emerging tech
- Notable tech coverage: WebAssembly (Figma, Google Sheets), React Native (Airbnb, Discord), PWAs (Flipkart)
- Testing & quality entries from Slack, BuzzFeed, LinkedIn
- Good reference when looking for "how did X solve Y at scale" pattern
